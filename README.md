# Sussurros

Mod de terror para Minecraft 26.2 (Fabric, Java 25), focado em presença, atmosfera e num comportamento que muda com o jeito de cada um jogar. Foi feito para ser jogado sem saber o que ele faz.

## Versão atual

A versão está no `gradle.properties` (linha `version=`). O que mudou em cada uma, em termos gerais e sem spoiler, está no `VERSAO-ATUAL.md`.

## Para quem vai jogar

- `LEIA-ME.md`: como preparar e abrir o jogo de teste.
- `ROTEIRO-DE-TESTE.md`: como testar e o que mandar de volta. Não tem spoiler.
- Não abra os arquivos marcados como SPOILERS (`DESIGN-SPOILERS.md`, `TELEMETRIA.md`, `PLANO-EXPANSAO.md` e a pasta `pesquisa/`): eles contam o que o mod faz.

## Para quem vai programar

- `CLAUDE.md`: comandos, regras do projeto e armadilhas do código.
- `ARQUITETURA.md` e `ROADMAP.md`: princípios e plano.

O projeto separa o Diretor (ritmo e decisões), as aparições, a entidade, a atmosfera, a memória e a investigação, para que as decisões de terror fiquem desacopladas da execução.
