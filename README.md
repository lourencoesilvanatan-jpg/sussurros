# Sussurros

Mod de horror para Minecraft focado em presença, stalking, atmosfera e comportamento contextual.

## Versão atual
0.9.0-alpha1

## Estrutura
O projeto separa Diretor, aparições, entidade Hóspede, atmosfera, memória e investigação, buscando manter as decisões de horror desacopladas da execução.

Este repositório está sendo usado como base de desenvolvimento do projeto.
